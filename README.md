# XO

Трекер воды, еды и ходьбы для Android. Одно кольцо «Баланс дня» показывает, как прошёл день. Голодание, сон, привычки, тренировки и самочувствие включаются по желанию.

Здесь лежат только готовые версии для установки. Кода в этом репозитории нет.

## Установить

1. Откройте [последнюю версию](https://github.com/skizewike/xoproject/releases/latest) с телефона.
2. Скачайте файл `XO-….apk`.
3. Откройте его. Если Android спросит, разрешите установку из этого источника.

Нужен Android 8 или новее. Приложение для взрослых (18+).

## Обновления

XO сам проверяет эту страницу раз в 12 часов. Когда выходит новая версия, приходит тихое уведомление, а в «Профиле» появляется строка «Обновление»: оттуда её можно скачать и установить. Ваши данные при обновлении сохраняются.

## Данные

Всё, что вы вводите, хранится только на телефоне. Аккаунтов, рекламы и аналитики нет. В сеть уходит только то, что вы отправили сами: фото или текст для подсчёта калорий и отметки общей привычки с другом. Подробно — в приложении: «Настройки → Политика конфиденциальности».

XO — дневник и калькулятор ориентиров, а не медицинское изделие.
